# Project tracking

Requirements: `docs/SCOPE.md`. Work items: **GitHub Issues**, titled with the
requirement ID. Evidence: issue comments. The workflow, the lifecycle and the
labels are in `docs/project-tracking.md` — read it before recording status.

The old `eje-tracker` application and database are retired. Do not read from
them, do not import from them, and do not build a replacement tracker.

Nothing is DONE without the owner's approval: tested is not approved, and
pushed is not deployed.
